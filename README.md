# MyMeido · 我的女仆

[中文](README.md) | [English](README_EN.md)

在 Minecraft 里养一个**属于你自己的女仆**：她会听话干活、会挨打还手、会自己过日子，
接上任意 OpenAI 兼容的模型之后，她还会**跟你聊天、记得住你们说过的话、主动来搭话**。

- Minecraft **1.21.1** + **Fabric**
- 单人 / 局域网 / 专用服务器都可以
- 没接 AI 也能用（她会用自带台词回应），接了 AI 才解锁真正的对话

---

## 功能一览

### 一、她会干活

| 模式 | 说明 |
|---|---|
| 游走 | 在自己家附近溜达，有怪会还手 |
| 原地待命 | 站在那儿不动 |
| 到这里来 | 走到你指定的位置 |
| 绑定家（床） | 记住「家」的位置，天黑了会自己回家过夜 |
| 钓鱼 | 自己甩竿、自己收竿，钓上来的东西按原版钓鱼表结算 |
| 种植 | 自己播种、等成熟、收割、补种（小麦 / 地狱疣） |
| 守卫前方 | 守在岗位方块上不乱跑，怪物靠近就迎上去打 |
| 丢弃物品 | 把背包里的东西丢到指定地点 |

- **背包**：她自己有一个背包，你放什么她用什么（背包里有食物她会自己吃、受伤了会吃）。
- **手上拿什么**：她要干活时才拿出对应的工具（钓鱼才拿竿、打架才拿武器），平时不占手。
- **夜里睡觉**：到家过夜时会把「可收纳的」东西放进床边的箱子里，食物 / 武器 / 护甲自己留着。
- **常驻加载**：她周围 3×3 区块会保持加载 —— 你走远了，她照样干活、照样回家。

### 二、她会打架

- 被打了会还手，性格上偏「打带跑」：拉开距离再打回去，不是站着换血。
- 守卫模式下怪物进入范围她会主动迎上去；手里有武器才动手。
- 被打 / 打人 / 高兴 / 难过都有表情变化（可以 `/mymeido emotion` 手动设）。

### 三、她会说话（需要你自己接一个模型）

两句话讲清楚：

- **不填 API** = 基础模式：右键点她，她会用自带台词回你；你打字她**不回复**（也**不会**主动搭话）。
- **填了 API** = API 模式：你在聊天栏打字她就回你；有上下文、有记忆、有人设、会主动搭话。

支持**任意 OpenAI 兼容端点**（本地 llama.cpp / LM Studio / Ollama 的 OpenAI 兼容口、
或任何在线服务），配置在 `config/mymeido/chat/api.txt`：

```ini
api_base_url=http://127.0.0.1:8080/v1    # 你的端点，注意要带 /v1
api_key=                                  # 需要鉴权就填
api_model=qwen3-4b                        # 模型名
```

改完 `/mymeido aireload` 生效，`/mymeido aistatus` 看当前状态，`/mymeido aiguide` 有完整指引。

顺手加的两个兼容开关（有些端点不吃标准那一套）：

```ini
# 对方报「不支持非流式」/ 400 带 stream 字样 → 改成 true 走 SSE
api_stream=false
# 额外的请求头，「名:值; 名:值」——应对「鉴权头不叫 Authorization」「要求伪装客户端头」这类端点
api_extra_headers=
```

**人设**：`config/mymeido/personas/<皮肤>.txt` 是她的性格 / 口癖 / 称呼 / 喜恶。
你手写的部分永远不会被覆盖；每轮对话之后她还会**自己把这段对话里学到的**合并进「自动区块」
（不想要就 `persona_auto_update=false`）。

**记忆**：说过的话、要点摘要都随存档保存（NBT 是唯一真相），
另在 `config/mymeido/memory/` 留一份可读的 Markdown 快照。

**她主动搭话**：用「女仆契约」造她的那位玩家，在她附近待够一段时间（默认 5 分钟），
**白天**她会自己走过来先跟你说句话；天黑就不打扰你。每小时最多 2 次，
台词由模型现想（会避开最近说过的、也会按你们现在的关系调整口吻）。
`/mymeido proactive` 看状态，`/mymeido proactive say` 可以立刻看效果。

**语言（中英双语）**：mod 的文案 —— 指令反馈、她的自带台词、生成的配置文件说明、
发给模型的提示词（也就是她跟你说话用的语言）—— 会**自动跟随游戏语言**：
中文环境说中文，其它语言一律英文。想固定的话，改
`config/mymeido/settings.txt` 里的 `language=auto|zh_cn|en_us`，或直接敲
`/mymeido lang <值>`（当场生效并写回）。物品名 / 按键名走游戏自带的多语言文件，
由你的游戏语言设置决定。

### 四、她记得你是谁

- **好感度**：对你好 / 送东西 / 一起打怪会长，挨打会掉（数值故意不显示，只影响口吻与情绪）。
- **女仆契约**：创建世界时会给一份契约，一份契约换一位女仆，物品栏层面就看得出来（堆叠上限 1，创造模式也照样消耗）。增加了合成表，契约可以获取。召唤女仆后会获得一个控制的指令闹钟。
- **指令闹钟**：代替契约的「找人」通道，可以隔着老远叫她过来，1对1的，不会串。

## 安装

1. 装 **Fabric Loader**（≥ 0.19.0）与 **Fabric API**，游戏版本选 **1.21.1**；
2. 把 `mymeido-x.y.z.jar` 丢进 `.minecraft/mods/`；
3. 启动游戏。首次启动会在 `config/mymeido/` 生成配置与模板。

## 快速上手

1. 做一张**女仆契约**：8 张纸围一圈 + 中间 1 个下界之星；
2. 右键契约 → 聊天栏里会列出可选的皮肤编号 → 输入编号，她就出现了；
3. 右键她打开模式菜单，选「游走」先让她自己待着。想派活就在聊天栏里按提示输入。

## 皮肤（重要）

**本 mod 不附带任何角色贴图。** 角色是**从文件夹里长出来**的：
**一张 png = 一个角色 = 选人菜单里的一个编号，数量不设上限。**
把图丢进 `.minecraft/config/mymeido/skins/` 就行，**文件名就是角色名**：

| 你放进目录的文件 | 菜单里显示 | 角色 id（存进存档的那个） |
|---|---|---|
| `yuuka.png` | `1) yuuka` | `yuuka` |
| `小鸟游星野.png` | `2) 小鸟游星野` | `小鸟游星野` |
| `Sakurai Momoka.png` | `3) Sakurai Momoka` | `momoka` ※ |

※ 老版本（0.1.0）里这位角色的 id 就是 `momoka`，所以**老存档和老人设卡继续有效**，
不会被改名成别的。以后新增的角色一律「id = 文件名去掉空格/下划线/大小写」。

- 编号按**文件名排序**自动生成，放几张就有几个可选；
- **加图 / 换图不用重启游戏**：按 `F3+T` 重载资源即可（会重扫目录 + 重读贴图）；
- 认 id 时忽略大小写、空格、下划线 —— `Sakurai Momoka.png` 与 `sakurai_momoka.png`
  会认成同一个角色（不会凭空多出一个）；
- 某张图找不到或读不出来 → 那只女仆**回落原版 Steve**，但她的角色 id 不变
  （所以删图不会让老存档里的女仆「换脸」）；
- **一张图都没放**时，菜单会给 4 个内置占位槽位（hoshino / rikka / kotone / momoka），
  贴图是原版 Steve —— 这样新装玩家右键契约不会毫无反应。放图进去它们就被顶掉了。

指令 `/mymeido skins` 可以看现在认到的是哪几个文件、目录在哪；
`/mymeido skins reload` 强制重扫一遍（同时补齐新角色的人设卡模板）。

皮肤的版权归原作者，请自行确认你有使用权 —— 这也是本 mod 不打包贴图的原因。

| 键 | 作用 |
|---|---|
| `G` | 打开打字框（多人服里要 `@名字`） |
| `H` | 打开对话历史面板（记忆要点 / 你说过的话 / 她说过的话） |

## 指令

```
/mymeido summon [皮肤]      召一位女仆
/mymeido mode <模式>        切换模式（原地待命 / 到这里来 / 钓鱼 / 种植 / 守卫前方 …）
/mymeido contract           拿到一张女仆契约
/mymeido alarm              用闹钟找她
/mymeido name <名字>        改名字
/mymeido skin <皮肤>        换皮肤
/mymeido skins [reload]     看皮肤库认到哪几个文件 / 重扫皮肤目录
/mymeido favor              看好感度档位
/mymeido chat <话>          直接跟她说一句（不用打字框）
/mymeido say <话>           让她念一句（不走模型）
/mymeido emotion [情绪]     手动设表情
/mymeido inventory          看她的背包
/mymeido proactive [say]    主动搭话：看状态 / 立刻说一句
/mymeido aistatus           看 AI 后端状态（地址 / 流式 / 自定义头 / 人设更新）
/mymeido aiguide            怎么把模型接起来（分几条路线讲）
/mymeido aireload           改完 api.txt 热重载
/mymeido lang [auto|zh_cn|en_us]  看 / 切这个 mod 说的语言（写 settings.txt）
/mymeido persona [extract]  看她的人设卡 / 让模型总结一次
/mymeido memory             看她的记忆要点
```

## 常见问题

**她不理我打的字？** 先 `/mymeido aistatus`：没填 API 就是基础模式（设计如此，只有自带台词）。
填了还不行就看是不是地址少了 `/v1`、模型名不对、或端点要求 `api_stream=true`。

**她只回空话 / 回复是空的？** 多半选了推理型模型（整段话在 `reasoning_content` 里）。
换一个非推理模型即可，`/mymeido aistatus` 会把这种情况指出来。

**创造模式物品栏里找不到东西？** 两件物品同时放在原版**「红石」**页；
自建的「我的女仆」页被 Fabric 排在**第 2 页**，点标签栏最右端的 `›` 翻页。

**打字框 / 历史面板背后世界很糊？** 1.21 默认给所有界面加了高斯模糊，本 mod 已换成半透明渐变。
如果你的整合包把它改回来了，是整合包里别的东西干的。
